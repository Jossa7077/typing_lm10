# Typing Messi ⚽

Aplicación web desarrollada con Laravel donde el usuario puede practicar mecanografía escribiendo frases relacionadas con Lionel Messi.

## Tecnologías usadas
- PHP
- Laravel
- Blade
- CSS
- JavaScript

## Instalación

git clone https://github.com/Jossa7077/typing_lm10.git
cd typing_lm10
composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
